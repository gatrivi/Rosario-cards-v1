## Gotchas discovered this session

- **CRA dev server under process supervisors:** `npm`/`npx` are `.cmd` shims — they die
  instantly when spawned via PTY supervisor. Working invocation:
  `node.exe node_modules/react-scripts/scripts/start.js` with `BROWSER=none CI=true`.
- **Browser tool quirks:** `timeout` param not honored on `run` (30s cap); a timed-out
  run can strand a stuck touch point — close the tab, reopen fresh; globalThis helpers
  don't survive a timeout rollback.
- **Edit-tool lint gap:** eslint did NOT flag six live imports clobbered during the
  extraction (build/tests caught it). After import surgery, always run tests before trusting lint.
