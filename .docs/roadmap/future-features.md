# Future Features (ideas)

## 1) Social gamification on the pilgrimage
- “Walk while praying”: user avatar advances visually along the Camino.
- Asynchronous encounters: see other users at the same stage.
- Key points: meet higher-level users.
- Leadership: advanced guides assemble/mentor new users behind them.

## 2) Physical verse pagination & scrolling
- “Pergamíno physics”: when a verse completes, it slides upward and new verses emerge from below.
- Manual verse movement: drag up/down with smooth touch scrolling.
- Mobile adaptation: one verse may occupy multiple physical lines; “foco” requires multiple finger passes (one per physical line) to complete the verse.

## 3) Monastic audio refinement
- Move from clean procedural oscillators toward large-space acoustics via convolution reverb.
- Add deep “silence + deep state persistence” robustness.
- Contemplative decay: if user leaves app idle ~10 minutes, lose a progress degree; text regresses (plateado) and must be reheated back to gold.
